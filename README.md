# 🇪🇸 Versión en Español

Bienvenido a mi portafolio personal de ingeniería de software. Este repositorio contiene una colección seleccionada de proyectos modulares y soluciones técnicas diseñadas para demostrar mis competencias clave en tres pilares principales: **Programación Orientada a Objetos (C++)**, **Computación Numérica (MATLAB)** y **Automatización Robótica Industrial (ABB RobotStudio)**.

## 🛠️ Catálogo de Proyectos

### ⚡ 1. Resolvedor de Mallas de Circuitos
* **Tecnologías:** MATLAB
* **Enfoque clave:** Simulación de álgebra lineal, manipulación de matrices y análisis de redes por nodos.
* **Descripción:** Un resolvedor interactivo para redes eléctricas complejas basado en las leyes de Kirchhoff. Estructura dinámicamente los parámetros del circuito en matrices algebraicas y calcula las corrientes de rama utilizando rutinas numéricas de alto rendimiento.
* **Explorar carpeta:** [`/01-Cirtuit-Resolver`](./01-Cirtuit-Resolver)

### ❌ 2. Tres en Raya Dinámico N×N
* **Tecnologías:** C++ (Entorno Dev-C++ / GCC)
* **Enfoque clave:** Matrices dinámicas multidimensionales, aritmética de punteros estricta y algoritmos escalables.
* **Descripción:** Una refactorización completa del juego clásico, eliminando las restricciones de tamaño fijo para permitir el escalado en tiempo de ejecución a cualquier tablero de dimensiones N × N. Implementa gestión de liberación de memoria y bucles parametrizados para validar vectores de victoria dinámicamente.
* **Explorar carpeta:** [`/02-Dynamic-TIC-TAC-TOE`](./02-Dynamic-TIC-TAC-TOE)

### 🤖 3. Soldador Autónomo ABB
* **Tecnologías:** ABB RobotStudio y Programación en RAPID
* **Enfoque clave:** Programación fuera de línea (OLP), secuenciación de coordenadas y máquinas de estado de seguridad.
* **Descripción:** Entorno de simulación industrial que gestiona una rutina de fabricación automatizada determinista para un brazo robótico ABB. Controla las trayectorias para costuras de soldadura continuas, la orientación de la herramienta y la verificación de espacios de trabajo libres de colisiones.
* **Explorar carpeta:** [`/03-ABB-Autonomus-Welder`](./03-ABB-Autonomus-Welder)

### ⚔️ 04. Sistema de Combate RPG
* **Tecnologías:** C++, Framework Qt y STL (Standard Template Library)
* **Enfoque clave:** Mecánicas de combate por equipos por turnos, patrones de diseño orientados a objetos, balance dinámico de inventario/tienda y serialización de archivos con marcas de tiempo.
* **Descripción:** Un videojuego de combate RPG equipo contra equipo por turnos desarrollado en C++ utilizando Qt y principios avanzados de POO. Cuenta con mecánicas de personajes polimórficos, un sistema automatizado de experiencia y niveles, balance dinámico de tienda e inventario, registro de batallas en tiempo real y persistencia del estado del juego mediante marcas de tiempo.
* **Explorar carpeta:** [`/04-RPG-Combat-System`](./04-RPG-Combat-System)

## 🚀 Entornos y Compilación

Los proyectos de este laboratorio han sido desarrollados y testeados en los siguientes entornos:
* **Sistemas Operativos:** Linux (Ubuntu LTS) y Windows 10/11.
* **Lenguajes y Herramientas:** C++17 (g++), MATLAB R2023b+ y ABB RobotStudio 6.x+.

# 🇺🇸 English Version

Welcome to my personal software engineering showcase. This repository is a curated collection of modular projects and technical solutions designed to demonstrate my core competencies across three main pillars: **Object-Oriented Programming (C++)**, **Numerical Computing (MATLAB)**, and **Industrial Robotics Automation (ABB RobotStudio)**.

## 🛠️ Project Catalog

### ⚡ 1. Circuit Mesh Resolver
* **Tech Stack:** MATLAB
* **Core Focus:** Linear algebra simulation, systems of equations, and electrical network modeling.
* **Overview:** An interactive solver for complex electrical networks using Kirchhoff's laws. It dynamically structures circuit parameters into algebraic matrices and computes branch currents utilizing high-performance numerical routines.
* **Explore Directory:** [`/01-Cirtuit-Resolver`](./01-Cirtuit-Resolver)

### ❌ 2. Dynamic N×N Tic-Tac-Toe
* **Tech Stack:** C++ (Dev-C++ / GCC toolchain)
* **Core Focus:** Multi-dimensional dynamic memory arrays, strict pointer arithmetic, and scalable algorithms.
* **Overview:** A complete refactor of the classic game layout, removing fixed constraints to allow real-time scaling to any N × N matrix grid. It implements memory cleanup management and parameterized loops to validate win vectors dynamically.
* **Explore Directory:** [`/02-Dynamic-TIC-TAC-TOE`](./02-Dynamic-TIC-TAC-TOE)

### 🤖 3. ABB Autonomous Welder
* **Tech Stack:** ABB RobotStudio & RAPID Programming
* **Core Focus:** Industrial offline programming (OLP), coordinate sequencing, and safety state machines.
* **Overview:** A simulation suite managing a deterministic automated manufacturing routine for an ABB industrial arm. It handles path adjustments for continuous welding seams, tool orientation, and collision-free workspace checking.
* **Explore Directory:** [`/03-ABB-Autonomus-Welder`](./03-ABB-Autonomus-Welder)

### ⚔️ 04. RPG Combat System
* **Tech Stack:** C++, Qt Framework & STL (Standard Template Library)
* **Core Focus:** Turn-based team combat mechanics, object-oriented design patterns, dynamic inventory/store balance, and timestamped file serialization.
* **Overview:** A C++ turn-based team-vs-team RPG combat game developed using Qt and advanced OOP principles. It features polymorphic character mechanics, an automated experience and leveling system, dynamic store and inventory balance, real-time battle logging, and timestamped game state persistence.
* **Explore Directory:** [`/04-RPG-Combat-System`](./04-RPG-Combat-System)
